\section*{Goal}

\section*{1) Exactly What Was Removed (Concrete)}

\subsection*{A. Repeated legal/banner comment blocks at file top}
From \texttt{Include/stm32f301x8.h} (V2), the following top block appears and is removed from the retrieval-focused V3 output:

\begin{lstlisting}[language=C]
/**
 ******************************************************************************
 * @file    stm32f301x8.h
 * @author  MCD Application Team
 * @brief   CMSIS STM32F301x8 Devices Peripheral Access Layer Header File.
 *
 * @attention
 *
 * Copyright (c) 2016 STMicroelectronics.
 * All rights reserved.
 *
 * This software is licensed under terms that can be found in the LICENSE file
 * in the root directory of this software component.
 * If no LICENSE file comes with this software, it is provided AS-IS.
 ******************************************************************************
 */
\end{lstlisting}

\textbf{How removed:}
\begin{itemize}
  \item Regex-based removal in \texttt{clean\_source\_code()} for comment blocks containing Copyright/ST/Licensed/SPDX.
  \item Implemented in \texttt{pipeline/cleaning/clean\_files\_v3.py} with \texttt{\_LICENSE\_BLOCK\_RE} and \texttt{\_LICENSE\_LINE\_RE}.
\end{itemize}

\subsection*{B. Massive repeated bitfield macro series (\_Pos/\_Msk)}
From \texttt{Include/stm32f301x8.h} chunk evidence (V2):

\begin{lstlisting}[language=C]
/********************  Bit definition for ADC_ISR register  ********************/
#define ADC_ISR_ADRDY_Pos              (0U)
#define ADC_ISR_ADRDY_Msk              (0x1UL << ADC_ISR_ADRDY_Pos)
#define ADC_ISR_EOSMP_Pos              (1U)
#define ADC_ISR_EOSMP_Msk              (0x1UL << ADC_ISR_EOSMP_Pos)
#define ADC_ISR_EOC_Pos                (2U)
#define ADC_ISR_EOC_Msk                (0x1UL << ADC_ISR_EOC_Pos)
...
\end{lstlisting}

\textbf{How removed:}
\begin{itemize}
  \item For giant CMSIS headers, V3 does not keep arbitrary \texttt{\#define} macro banks.
  \item V3 reconstructs a compact representation from 3 kept sections only: IRQ enum, base addresses, and \texttt{\_TypeDef} register structs.
  \item This behavior is explicit in \texttt{filter\_cmsis\_device\_header()} docstring: drops \texttt{XXX\_Pos} / \texttt{XXX\_Msk} lines.
\end{itemize}

\section*{2) What Is Kept (to avoid losing important info)}
For the same file in V3, the kept summary states:

\begin{lstlisting}
/* CMSIS Device Header - Filtered for RAG relevance */
/* Original: 698,576 chars, 6,565 #defines */
/* Kept: IRQ enum, 63 base addresses, 22 peripheral structs */
\end{lstlisting}

Kept content includes:
\begin{itemize}
  \item IRQ vectors: interrupt names and numbers used in debugging and fault triage.
  \item Base addresses: \texttt{PERIPH\_BASE}, \texttt{GPIOA\_BASE}, etc.
  \item Register layouts: \texttt{typedef struct ... \_TypeDef;} used for register map understanding.
\end{itemize}

\section*{4) RAG Value and Why This Is Defensible}
\textbf{RAG effect:}
\begin{itemize}
  \item Much denser technical evidence per token.
  \item Fewer false lexical matches caused by repetitive macro banks.
  \item Better context budget usage for question-relevant signals.
\end{itemize}

\textbf{Not losing critical information:}
\begin{itemize}
  \item High-value troubleshooting anchors are preserved (IRQ/base/register layout).
  \item Original full source remains reachable via \texttt{github\_url} for deep bit-level investigations.
  \item If strict bitfield recall is required, a fallback path can query full headers on demand.
\end{itemize}

\section*{5) One-line Defense Statement (for Jury)}
\textit{Cleaning V3 does not delete project knowledge; it removes repetitive retrieval noise and keeps the highest-value hardware evidence for faster, more reliable RAG answers.}

\section*{Appendix: Exact Cleaning Logic}
Implemented in:
\begin{itemize}
  \item \texttt{pipeline/cleaning/clean\_files\_v3.py}
\end{itemize}

Key rules:
\begin{itemize}
  \item \texttt{clean\_source\_code()} removes legal/banner boilerplate with regex patterns.
  \item \texttt{is\_cmsis\_device\_header()} activates giant-header filtering (size threshold 100KB).
  \item \texttt{filter\_cmsis\_device\_header()} keeps IRQ/base/typedef and drops massive \texttt{\_Pos/\_Msk} banks.
\end{itemize}
