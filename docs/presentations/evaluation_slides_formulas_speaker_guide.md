## Slide A - Alfred Vision: Contextual Trust

Slide objective:
- Show that success is not only API availability, but contextual anchoring quality.

Formula to present:
- Contextual Trust (%) = (number of evaluated items with coherence score C >= tau) / N_evaluated * 100.

Report alignment:
- Definition from Equation eq:confiance_contextuelle_def.
- Alert threshold tau = 0.12 (Section justification des seuils).

Numbers to explain on slide:
- Issue screenshots: (200 - 3) / 200 = 98.5%.
- PDF figures: (242 - 141) / 242 = 41.7%.

What each term means:
- N_evaluated: number of images/figures evaluated.
- C: coherence score generated by validate_alfred_coherence.py.
- tau: anomaly threshold below which text is considered weakly anchored.

30-second jury script:
- We measure not only if Alfred returns text, but if this text is grounded in technical context.
- We use a coherence threshold tau=0.12 and compute the ratio of anchored items.
- This gives 98.5% for issue screenshots and 41.7% for PDF figures, which confirms that screenshot context is richer than standalone PDF context.

## Slide B - Comparative Study: Generic LLM vs Persona KB

Slide objective:
- Quantify the quality improvement delivered by KB-first persona compared with generic Alfred baseline.

Formula to present:
- Gain (%) = (Score_persona - Score_alfred) / Score_alfred * 100.

Numbers to explain on slide:
- Score_alfred = 5.8/10.
- Score_persona = 8.1/10.
- Gain = (8.1 - 5.8) / 5.8 * 100 = 39.7% (reported as +39%).

Report alignment:
- Comparative section: Etude Comparative: Alfred Generique vs Persona KB.
- KPI table with score per answer, verifiable citations, and actionable fix rate.

Important speaking note:
- Clarify that +39% is relative improvement over baseline score, not absolute points.

30-second jury script:
- The mean score moves from 5.8 to 8.1 out of 10.
- Using relative gain formula, this is about +39% quality improvement.
- The gain is not only in score but also in traceability: verifiable citations increase from 0% to 87%.

## Slide C - KB Strategy Formula (when discussing configuration)

Slide objective:
- Explain how retrieval strategy candidates are ranked.

Formula to present:
- S = 0.40*R_top1 + 0.20*R_top3 + 0.35*R_answer - 0.15*R_hallucination - 0.05*(1 - B_latency).
- B_latency = 1 - (latency - min_latency) / (max_latency - min_latency).

How to explain weights:
- Top-1 relevance and final answer correctness carry the highest weights.
- Hallucination is penalized.
- Latency contributes as a secondary optimization term.

30-second jury script:
- We use a weighted score balancing retrieval quality, final answer quality, hallucination risk, and latency.
- This formula allows us to compare strategy profiles objectively and select a stable production setting.

## Slide D - Quality Index Offline vs Online

Slide objective:
- Explain how manual offline scoring and platform online scoring are compared.

Formulas to present:
- QI_offline = (total_0_to_7 / 7) * 100.
- Delta = QI_online - QI_offline.

Report alignment:
- QI definition in chapter evaluation (Equation eq:qi_def).
- Offline rubric criteria aligned with traceability, factual correctness, and actionability.

30-second jury script:
- Offline we score each answer with an expert rubric, then normalize to /100.
- Online we use the platform quality index.
- Delta shows whether runtime behavior overperforms or underperforms manual benchmark expectation.

## What To Avoid During Defense

- Do not say API success equals quality.
- Do not mix absolute point difference with percentage gain.
- Do not present +39% without showing the formula once.
- Do not discuss strategy rank without citing the weighted score formula.

---

## Quick One-Line Summary For Jury

- Alfred trust uses an anchoring ratio formula, comparative gain uses a relative improvement formula, strategy ranking uses a weighted multi-factor score, and QI comparison uses normalized offline score versus online score delta.
